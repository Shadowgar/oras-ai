# Integration Boundaries

## WordPress
Host, identity session, admin capability, source-discovery, and request framework.

## Paid Memberships Pro
Membership eligibility and member-state source. Not a free-form knowledge source.

## WooCommerce
Authority for products, prices, stock/availability, orders, and checkout URLs. Products are live by default.

## The Events Calendar
Authority for current event records. `tribe_events` is live by default.

## Fluent Support
Human-support system of record. ORAS AI does not build a competing ticket lifecycle.

## OpenAI
Language reasoning, structured classification/extraction, and answer generation behind an internal provider adapter. Keys remain server-side.

## Astronomy/weather
Provider selection is deferred. Adapters return normalized internal data so orchestration does not depend on one provider schema.

## Links
Member-facing action links come from known canonical ORAS URLs or validated allowlisted provider results. Arbitrary user input is never used as an unchecked redirect/action URL.
