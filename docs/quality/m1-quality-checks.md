# M1 Quality Checks

Run the complete M1 Step 1 quality scaffold with:

```bash
npm run quality
```

Equivalent individual commands:

```bash
npm run lint:php
npm run lint:js
npm test
```

These checks provide PHP syntax linting, JavaScript syntax checking, and the initial WordPress-stubbed PHP smoke test. Characterization tests for scanner behavior are expected in the next M1 step.
