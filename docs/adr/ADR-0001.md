# ADR-0001: Modular WordPress plugin architecture

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

ORAS AI lives inside an existing WordPress site and needs deep access to WordPress plugin capabilities.

## Decision

Use a modular WordPress plugin for the initial architecture. Preserve clear internal module boundaries so pieces can later be extracted only when measured operational need justifies it.

## Consequences

Deployment stays simple and reuses WordPress identity/data. Scale-out services remain possible later.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
