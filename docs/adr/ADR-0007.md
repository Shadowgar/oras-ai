# ADR-0007: Static, live, mixed, ignore, and review knowledge classes

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

One page can mix stable descriptive content with changing dates/prices/availability.

## Decision

Use five classes: Static Knowledge, Live Data, Mixed, Ignore, Needs Review.

## Consequences

Mixed-source extraction becomes a core ingestion feature rather than forcing one classification on an entire page.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
