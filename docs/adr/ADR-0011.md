# ADR-0011: General astronomy knowledge boundary

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

Members want astronomy education beyond website FAQs.

## Decision

Allow non-current general astronomy questions to use model knowledge inside the astronomy domain.

## Consequences

ORAS AI becomes an astronomy mentor as well as site help, while ORAS policy still requires ORAS evidence.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
