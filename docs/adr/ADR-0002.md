# ADR-0002: AI provider abstraction and OpenAI Responses API

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

Model/provider capabilities and prices change over time.

## Decision

Put AI calls behind an internal provider interface. The initial provider uses OpenAI's Responses API. Model selection is configuration/qualification, not business logic.

## Consequences

GPT-5.6 Luna can serve cost-sensitive workflows without locking ORAS to one model forever.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
