# ADR-0006: Rule-first knowledge ingestion

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

WordPress source types often reveal semantics more reliably than AI.

## Decision

Apply deterministic source-type and utility-page rules before AI classification.

## Consequences

Events/products/templates are handled consistently and scanner API cost is lower.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
