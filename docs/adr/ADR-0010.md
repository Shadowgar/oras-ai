# ADR-0010: Structured live ORAS connector layer

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

ORAS live data spans multiple plugins/services.

## Decision

Expose normalized, least-privilege connector interfaces for Events Calendar, WooCommerce, PMPro, Fluent Support, astronomy, weather, and future systems.

## Consequences

Orchestration avoids vendor database/schema coupling.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
