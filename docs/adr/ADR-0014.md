# ADR-0014: Fluent Support as support system of record

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

ORAS already uses Fluent Support.

## Decision

Use Fluent Support as the support system of record. ORAS AI performs intake, classification, summarization, routing, and confirmed ticket creation. The initial routing model uses one primary ORAS Support mailbox, configurable topic tags/team/agent mappings, and a General ORAS Support fallback. Individual people are not hard-coded.

## Consequences

No duplicate support lifecycle is built. Resolved tickets may inform knowledge review but never auto-approve policy.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
