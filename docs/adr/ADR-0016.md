# ADR-0016: Usage quotas and cost controls

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

AI usage creates direct variable cost.

## Decision

Require member quotas, burst limits, input/output/tool budgets, changed-source-only scanning, bounded retrieval, caching, and usage accounting. Initial production limits are 25 allowed AI questions/day and 150/month per member, 5 requests/minute burst, a $10/month site-wide OpenAI spend warning, and a $20/month site-wide hard stop.

## Consequences

Budget protection is a release requirement, not optional optimization.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
