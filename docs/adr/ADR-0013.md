# ADR-0013: Application-enforced authorization and tool security

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

Prompt instructions are not a secure authorization mechanism.

## Decision

Enforce identity, visibility, tool allowlists, argument validation, URL policy, and side-effect confirmation in application code outside the model.

## Consequences

Prompt injection cannot grant capabilities even if it influences model prose.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
