# ADR-0012: Current astronomy and weather data boundary

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

Current sky/weather facts become stale quickly.

## Decision

Use current provider data or deterministic calculations for celestial state, observing windows, and weather. M0 freezes normalized capability contracts for both astronomy and weather; the specific astronomy library/provider and weather provider are selected during M6 after qualification.

## Consequences

Observing recommendations are time-aware and evidence-driven.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
