# ADR-0009: Fact-level source precedence

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

The model may encounter conflicting source claims.

## Decision

Apply fact-level authority: live ORAS state > approved ORAS policy > synchronized ORAS knowledge > current astronomy/weather > general model knowledge > escalation.

## Consequences

Lower-authority text cannot win merely because it is phrased confidently.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
