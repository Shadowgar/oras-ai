# ADR-0005: Off-topic prefilter before primary answer workflow

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

Sending obvious off-topic prompts to the primary answer workflow wastes tokens.

## Decision

Use staged domain control: local/rule checks first, low-cost model classification only when ambiguous, and primary answer generation only after allow.

## Consequences

Obvious abuse becomes cheap to reject while ambiguous legitimate astronomy questions can still be recognized.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
