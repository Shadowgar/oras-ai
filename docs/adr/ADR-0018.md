# ADR-0018: Accessibility as release requirement

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

Chat is a core member web function.

## Decision

Treat keyboard and assistive-technology accessibility as a release requirement.

## Consequences

Progress, sources, actions, errors, and confirmation dialogs require accessible semantics.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
