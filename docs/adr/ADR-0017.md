# ADR-0017: Privacy, context minimization, and configurable retention

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

Member conversations/support context may contain personal information.

## Decision

Minimize external context and exclude payment/secrets. Initial production retention is 30 days for AI conversation text and 12 months for usage/cost metadata without full conversation text. Fluent Support tickets follow their separate support-retention policy.

## Consequences

Analytics should prefer aggregate/de-identified data when raw messages are unnecessary.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
