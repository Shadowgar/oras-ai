# ADR-0008: Source provenance, synchronization, and retirement

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

Automatically derived knowledge can become stale or orphaned.

## Decision

Keep provenance, hashes, extraction version, freshness, and lifecycle for every scanner-managed artifact. Missing/reclassified sources retire managed knowledge. Manual knowledge is protected.

## Consequences

Knowledge remains auditable/synchronizable rather than becoming an untraceable answer pile.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
