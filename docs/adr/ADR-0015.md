# ADR-0015: No autonomous purchasing in initial architecture

**Status:** Accepted  
**Date:** 2026-08-16
**Accepted:** 2026-08-27

## Context

The assistant may recommend passes/tickets, but autonomous commerce adds risk.

## Decision

Allow validated product/action links. Keep checkout/payment as normal WooCommerce/member actions.

## Consequences

No card handling or autonomous order finalization by ORAS AI.

## Reconsider when

Reconsider only when operating evidence, product scope, plugin capability, security/privacy requirements, cost, or deployment constraints materially change the assumptions behind this decision.
