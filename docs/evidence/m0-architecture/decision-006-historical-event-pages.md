# M0 Decision 006 — Historical Event Page Indexing

**Status:** Resolved during M0 review

## Decision

Historical event pages remain searchable as **Historical Event Knowledge**.

They are useful for questions such as:
- who spoke at a past ORAS event;
- what activities were offered at a prior AstroBlast;
- whether ORAS has held a certain workshop before;
- what a past event schedule contained.

## Retrieval priority

Historical event content has lower retrieval priority than:
1. current live event records;
2. current approved ORAS event/program pages.

Historical content is retrieved only for clearly historical, past, previous, or comparative intent.

## Prohibited use

Historical event pages must not answer current/upcoming facts such as next event date, current schedule, registration deadline, current pricing, or current ticket/pass availability.

This remains part of the Draft M0 package until the complete M0 architecture is owner-approved and frozen.
