# M0 Decision 001 — ORAS AI Member Eligibility

**Status:** Resolved during M0 review

**Decision:** Any logged-in user with an active ORAS membership, regardless of membership level, may use ORAS AI. WordPress administrators may use ORAS AI for administration/testing even without an active membership.

| User state | AI access |
|---|---|
| WordPress administrator | Allow |
| Logged-in user with any active ORAS membership | Allow |
| Logged-in user without an active ORAS membership | Deny |
| Anonymous visitor | Deny |

This remains part of the Draft M0 package until the complete M0 architecture is owner-approved and frozen.
